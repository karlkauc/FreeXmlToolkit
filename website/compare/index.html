Where the others offer more

FreeXmlToolkit focuses on XML, XSD, XSLT and XQuery development. It edits DTD and RELAX NG as text only, and its Large File Viewer is read-only.

Oxygen XML Editor

  • DITA, DocBook and TEI authoring and publishing
  • Visual author mode with change tracking
  • XML databases, CMS and WebDAV
  • Eclipse plugin and web editor

XMLSpy

  • Database connections
  • Code generation for Java, C# and C++
  • WSDL editor, SOAP client, XBRL taxonomy editor
  • Authentic view, charts, IDE integration

Liquid Studio

  • Data Mapper with databases, EDI and CSV
  • Code generation from schemas
  • WSDL editor and web service test client
  • Editing files larger than memory
