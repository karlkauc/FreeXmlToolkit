FAQ

Questions before you download

What it costs, who makes it, what it does with your data. For problems while using the application, see Troubleshooting in the documentation.

Is it really free?

Yes. FreeXmlToolkit is open source under the Apache 2.0 licence. There is one edition with every feature, no trial period, no account and no licence key. You may use it at work and in a company without paying.

Who is behind it, and how is it paid for?

The application is developed by Karl Kauc in Austria and published on GitHub. There is no paid edition; sponsors help to pay for code signing, hosting and time. See About.

Is it maintained?

Yes. New versions appear regularly; the news page lists them, and the full release notes are in the documentation. The application checks for updates and installs them when you agree.

Which systems does it run on?

Windows 10 and 11 (x64), macOS on Apple Silicon and Intel, and Linux (x64) with a .deb, an .rpm or a portable ZIP. Every package contains its own Java runtime, so there is nothing else to install, and the installers need no administrator rights.

What can it do that I pay for elsewhere?

A graphical XSD editor for XSD 1.1, Schematron with Quick Fixes, a debugger for XSLT, XQuery and Schematron, XProc 3.0, XSpec, PDF output, XML signatures and encryption, compare and merge, a command line and an MCP server. The comparison with Oxygen XML Editor, XMLSpy and Liquid Studio also says where those products offer more.

Does it send my documents anywhere?

No. Documents are processed on your computer. Anonymous usage statistics and error reports are on by default and can be switched off; they never contain file names, paths or document content. Online lookups and the AI assistant only run when you switch them on or click them. See Privacy and telemetry.

Does it work without an internet connection?

Yes. Schemas you used before come from the cache or the Schema Library, and nothing in the application requires a network. See Operation without internet.

Can it open very large files?

Yes. Files from 50 MB open in the Large File Viewer, which reads only the part it shows; a file of one gigabyte opens in seconds. You can search it, browse its structure, validate it and edit a part of it. See Large files.

Is there AI in it?

Only if you want it. The assistant is off by default and works with a local model or a provider you choose. Every answer is checked by the application before you see it, and an administrator can remove the feature. See AI and automation.

Can we roll it out in a company?

Yes. There is an MSI package and a silent installation, machine-wide policies for settings, updates and telemetry, an SBOM with every release and a documented threat model. See Enterprise.

In which languages is the interface?

English and German. The documentation is in English.

Where do I get help?

The documentation has guides for every area and a page for troubleshooting. Problems and ideas go to the issue tracker on GitHub.
