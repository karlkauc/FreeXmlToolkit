Namespace

XML Schema extensions

This address is an XML namespace name. FreeXmlToolkit writes a few elements of its own into xs:appinfo of a schema, and these namespaces identify them. Nothing is loaded from here: a namespace name only has to be unique.

http://freexmltoolkit.org/xml-schema-extensions

fxt:exampleValues holds example values of an element or attribute. The toolkit shows them in the generated documentation (“Sample Data”), offers them in the editor's auto-completion and uses them when it generates sample XML.

<xs:appinfo>
  <fxt:exampleValues xmlns:fxt="http://freexmltoolkit.org/xml-schema-extensions">
    <fxt:example value="TRX-0815"/>
  </fxt:exampleValues>
</xs:appinfo>

The Altova form altova:exampleValues (namespace http://www.altova.com/xml-schema-extensions) is read as well.

http://freexmltoolkit.org/schema/flattening

fxt:sourceFile records which included file a component came from when a schema made of several files is flattened into one.

Other schema processors

Validators ignore the content of xs:appinfo, so these elements change nothing about how a schema validates.

All tags the toolkit reads from schema annotations: XSD documentation tags.
