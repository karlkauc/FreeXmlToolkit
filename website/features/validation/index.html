Schemas

Validation while you type

The document is checked against its schema as you edit, and problems are marked in the text.

  • XSD 1.0 and 1.1
  • DTD and RELAX NG, in XML and compact syntax
  • JSON Schema for JSON and YAML documents
  • The schema is taken from the document, the project or the Schema Library
Read the documentation
Schematron

Business rules with Quick Fixes

Schematron rules check what a schema cannot express, and Quick Fixes repair the document.

  • A fix is one undo step and keeps the formatting of the document
  • A rule builder and templates for writing rules
  • Step through a Schematron in the debugger
Read the documentation
Problems

Thousands of problems, still readable

The Problems panel groups, filters and exports what a validation found.

  • Group by object, by rule or by category
  • Errors, warnings and hints, with search
  • Export to Excel, also per group
Read the documentation
Folders and projects

Whole folders at once

Validate every file of a folder or of a project and keep the result as a report.

  • A project binds schemas and Schematron rules to files by pattern
  • The same check from the command line, with JUnit and SARIF reports
