PDF

PDF with XSL-FO

XML and a stylesheet become a PDF, shown in the application.

  • Apache FOP built in, with PDF/A-1b output
  • The intermediate FO and every message of the processor at hand
  • Antenna House, RenderX XEP or another processor instead of FOP
  • From the command line with fxt-cli fop
Read the documentation
Signatures

Sign and verify

XML signatures with the algorithms you choose.

  • RSA, RSA-PSS and ECDSA
  • Create RSA or EC certificates for tests
  • Keystores, PEM and DER files
Read the documentation
Encryption

Encrypt elements or whole documents

XML Encryption 1.1 for one element, its content, the document or a binary file.

  • Any number of recipients: certificates, shared keys or a password
  • Inspect an encrypted file before decrypting it
  • Encrypt Element and Decrypt in the editor's context menu
Read the documentation
