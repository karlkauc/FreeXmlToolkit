Vergleichen

Unterschiede in der Struktur, nicht in den Zeichen

Der XML-Modus vergleicht Elemente und Attribute; Formatierung und Attributreihenfolge zählen nicht.

  • Teile des Dokuments per XPath ignorieren
  • Eine Toleranz für Zahlen
  • Ein Textmodus für alles, was nicht XML ist
Zur Dokumentation (englisch)
Ordner

Zwei Ordner nebeneinander

Welche Dateien hinzugekommen, entfernt oder geändert sind, und die Unterschiede jeder einzelnen.

  • Den Vergleich einer Datei aus der Liste öffnen
Zur Dokumentation (englisch)
Zusammenführen

Drei-Wege-Merge

Zwei geänderte Versionen einer Datei mit ihrem gemeinsamen Vorgänger zusammenbringen.

  • Konflikte werden so markiert, wie Git sie markiert
  • Auch als fxt-cli merge
Zur Dokumentation (englisch)
Konvertieren

XML nach Excel und zurück

Datensätze eines XML-Dokuments werden zu Zeilen einer Excel- oder CSV-Tabelle, und die Tabelle wird wieder zu XML.

  • Eine Zeile je Datensatz, mit Vorschau vor dem Export
  • XML, JSON und YAML in jede Richtung
  • Auch als fxt-cli convert
