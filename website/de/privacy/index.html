Server-Logdateien

Wenn Sie eine Seite aufrufen, zeichnet der Webserver unseres Hosting-Anbieters technische Daten auf, die Ihr Browser sendet: IP-Adresse, Datum und Uhrzeit, die angeforderte Seite, die verweisende Seite, den Browser und das Betriebssystem. Das ist nötig, um die Website auszuliefern und sicher zu betreiben (Art. 6 Abs. 1 lit. f DSGVO). Die Daten werden nicht mit anderen Daten zusammengeführt und vom Anbieter nach kurzer Zeit gelöscht.

Aktuelle Version von GitHub

Die Download-Schaltflächen fragen direkt aus Ihrem Browser bei der öffentlichen Schnittstelle von GitHub (api.github.com) die aktuelle Version ab, damit sie auf die aktuellen Dateien zeigen. GitHub erhält dabei Ihre IP-Adresse und Angaben zu Ihrem Browser. Die Downloads selbst werden von GitHub ausgeliefert. Es gilt die Datenschutzerklärung von GitHub: GitHub General Privacy Statement. Die Antwort wird eine Stunde lang im Sitzungsspeicher Ihres Browsers aufbewahrt, der gelöscht wird, wenn Sie den Tab schließen.

Links zu anderen Websites
