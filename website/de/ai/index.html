KI und Automatisierung

KI zu Ihren Bedingungen

Ein Assistent, dessen Antworten geprüft werden, bevor Sie sie sehen, ein Server, der KI-Agenten echte XML-Werkzeuge gibt, und eine Kommandozeile für Ihre Build-Pipeline.

KI-Assistent

Antworten, die zuerst geprüft werden

Die Anwendung kompiliert, startet, validiert und vergleicht, was das Modell vorschlägt, und schickt die Fehler für bis zu drei Korrekturrunden zurück. Nichts wird ohne Sie übernommen oder gespeichert.

  • Validierungsprobleme erklären und beheben
  • Aus einer Frage XPath oder XQuery machen
  • Ein XSLT-Stylesheet aus einem Zielbeispiel erzeugen
  • Standardmäßig aus; ein lokales Modell (Ollama, LM Studio) oder ein Anbieter, bei dem Sie ein Konto haben
  • Datenstufen und eine Vorschau jeder Anfrage bestimmen, was Ihren Computer verlässt
Der KI-Assistent
MCP-Server

Geben Sie Ihrem Agenten XML-Werkzeuge

fxt-cli mcp bietet Claude Code und jedem anderen Client des Model Context Protocol Validierung, XPath, XQuery, XSLT, XSpec, Schematron, Schema-Abfragen und Vergleich. Der Agent prüft seine eigene Arbeit, statt zu raten.

  • Läuft auf Ihrem Rechner über Standardeingabe und -ausgabe, ohne Netzwerk-Port
  • Nur lesend und auf die Ordner beschränkt, die Sie angeben
  • Ruft kein Sprachmodell auf und sendet nichts irgendwohin
MCP-Server
# bei Claude Code anmelden
$ claude mcp add fxt -- fxt-cli mcp --root .

# die Werkzeuge auflisten
$ fxt-cli mcp --list-tools
Kommandozeile

Dieselben Engines in Ihrem Build

fxt-cli wird mit der Anwendung installiert. Es validiert, transformiert, fragt ab, führt XSpec-Tests und Szenarien aus, vergleicht, signiert und verschlüsselt – und berichtet als Text, JSON, JUnit oder SARIF.

CI-Rezepte für GitHub Actions und GitLab CI
$ fxt-cli validate data/ --xsd schema.xsd -f junit -r report.xml
$ fxt-cli transform in.xml -s style.xsl -o out.html
$ fxt-cli xspec tests/invoice.xspec -r results.xml
$ fxt-cli compare expected.xml actual.xml
