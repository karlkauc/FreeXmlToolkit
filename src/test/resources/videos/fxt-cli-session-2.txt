$ fxt-cli --help
FreeXmlToolkit on the command line.
Usage: fxt-cli [-hqV] [--verbose] [COMMAND]

Description:
Validate, transform, test (XSpec), compare, merge, document schemas, convert
and render PDF without the user interface, or serve these tools to AI agents
(mcp). Logs go to standard error, results to standard output.

Options:
  -h, --help      Show this help message and exit.
  -q, --quiet     Print nothing but errors and requested reports.
  -V, --version   Print version information and exit.
      --verbose   Log details of the processing to standard error.

Commands:
  validate   Validate XML, JSON and project files against schemas and
               Schematron.
  transform  Run an XSLT stylesheet, an XQuery or an XProc pipeline.
  query      Evaluate an XPath, XQuery or JSONPath expression against files.
  xsd-doc    Generate the documentation of an XML Schema (HTML site, PDF or
               Word).
  convert    Convert between XML, JSON and YAML.
  compare    Compare two XML, JSON or YAML files by structure, or two folders
               file by file.
  merge      Three-way merge of XML or text files with Git conflict markers.
  xspec      Run XSpec tests for XSLT, XQuery and Schematron.
