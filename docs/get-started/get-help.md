# Get help

- **Look it up.** The [FAQ & troubleshooting](../reference/faq.md) page answers common questions;
  the [Glossary](../reference/glossary.md) explains the terms used in the application.
- **Try it on an example.** [First steps](first-steps.md) uses the bundled example; the `examples/`
  folder of the installation has larger samples for every tool.
- **Report a problem.** Open an issue on the project's
  [GitHub page](https://github.com/karlkauc/FreeXmlToolkit/issues), or send an anonymous report
  from inside the application with **Help → Report a Problem…**.
- **Report a security issue privately.** See [Reporting a vulnerability](../extend/security-policy.md).
- **Contribute.** Read the [Contributing guide](../extend/contributing.md) and the
  [Code of conduct](../extend/code-of-conduct.md).
