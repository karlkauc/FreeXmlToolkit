# Glossary

The terms the application and this documentation use, in alphabetical order.

Activity
:   One of the tools in the activity bar: Explorer, Search, Favorites, Validation, Transform,
    Schema, Schema Library, PDF / FOP, Sign & Encrypt, Settings, plus the activities of enabled
    extensions. Selecting an activity shows its side panel.

Activity bar
:   The column of icons at the left edge of the window. See the
    [Tour of the workspace](../get-started/workspace-tour.md).

Binding
:   The link between a document and the schema it is validated against. A document can name its
    schema itself, the [Schema Library](../guides/design-schemas/schema-library.md) can supply
    one by namespace, or a [project](../guides/projects.md) can bind schemas to files by pattern.

Bookmark
:   A marked line in a text editor that you can name, number and jump to. See
    [Bookmarks](../guides/edit-xml/bookmarks.md).

Catalog
:   An OASIS XML catalog: a file that maps public identifiers, system identifiers and URIs to
    local schema files. See [Schema Library](../guides/design-schemas/schema-library.md).

Editor tab
:   One open file in the middle of the window. Tool results such as a comparison or a PDF preview
    open as tabs too.

Extension
:   An optional part of the application for one standard or industry, such as FundsXML or
    ISO 20022, switched on in the settings. See [Industry standards](../industry/index.md) and
    [Manage extensions](../industry/manage-extensions.md).

Favorite
:   A file or folder you have starred for quick access. See
    [Favorites](../guides/edit-xml/favorites.md).

fxt-cli
:   The command-line program installed with the application. See
    [Command line](../automate/command-line.md).

Grid
:   The Graphic view of an XML or JSON document: nested rows, with repeating elements shown as
    tables. See [Grid view](../guides/edit-xml/grid.md).

MCP server
:   `fxt-cli mcp`, which offers the validation, query and transformation engines to AI agents
    as tools. See [MCP server](../automate/mcp-server.md).

OUTPUT panel
:   The panel below the editor that shows the result and the messages of a transformation.

Plugin
:   The programming interface behind extensions; a jar file that adds activities, menu items,
    validators or schemas. See [Writing plugins](../extend/writing-plugins.md).

Policy
:   A machine-wide file with which an administrator locks settings or sets defaults. See
    [Policies](../administer/policies.md).

PROBLEMS panel
:   The panel below the editor that lists validation findings. See
    [Working with problems](../guides/validate/problems.md).

Project
:   A `.fxtproj` file that holds folders, schema bindings, catalogs and scenarios. See
    [Projects & scenarios](../guides/projects.md).

Properties (Inspector)
:   The panel at the right edge of the window. It shows, and for many nodes edits, the selected
    node. See [Properties Inspector](inspector.md).

Query Console
:   The panel for XPath, XQuery and JSONPath queries against the open document. See
    [Query console](../guides/transform-query/query-console.md).

Quick Fix
:   A repair that a Schematron rule offers for its own finding (Schematron Quick Fixes, SQF). See
    [Schematron Quick Fixes](../guides/validate/schematron-quick-fixes.md).

Scenario
:   A named transformation in a project: stylesheet, input, parameters and output. See
    [Projects & scenarios](../guides/projects.md).

Schema Library
:   The page that manages namespace-to-schema mappings, catalogs and the schema cache. See
    [Schema Library](../guides/design-schemas/schema-library.md).

Side panel
:   The panel next to the activity bar; its content belongs to the selected activity.

Template
:   A reusable snippet or document skeleton. See [Templates](../guides/edit-xml/templates.md).

View mode
:   The way the editor shows a document: **Text**, **Tree** or **Graphic**; schemas also have
    **Overview**, HTML files have **Preview** instead of Tree and Graphic.
