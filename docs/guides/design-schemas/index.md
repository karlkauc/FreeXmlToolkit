# Design schemas

Open an `.xsd` file and the editor shows it as text, as a tree or as a diagram; the **Schema**
activity adds the type library, analysis, documentation and sample data. Every edit goes through
the same undo history, whichever view you make it in.

| Task | Page |
|------|------|
| See what the Schema activity offers | [The Schema panel](schema-panel.md) |
| Edit the schema as a diagram: cards, drag and drop, type frames | [Graphic view](graphic-view.md) |
| Manage all top-level components in one table | [Overview view](overview-view.md) |
| Browse named types, see where they are used, edit one type on its own | [Types](types.md) |
| Edit the source, and schema properties from any view | [Text view](text-view.md) |
| Statistics, unused types, quality checks, identity constraints | [Schema analysis](analysis.md) |
| HTML, Word or PDF documentation of a schema | [Generate schema documentation](documentation.md) |
| A first draft of a schema from an XML document | [Generate a schema from XML](generate-from-xml.md) |
| A sample document from a schema | [Generate sample XML](sample-xml.md), [with profiles](sample-xml-profiles.md) |
| One standalone file from a schema with includes | [Flatten a schema](flatten.md) |
| Namespace mappings, catalogs and the schema cache | [Schema Library](schema-library.md) |

Which XSD features are supported is listed under [Schema support](../../reference/schema-support.md).

In the Tree and Graphic views, **Delete** removes the selected node, and **Ctrl+Z** / **Ctrl+Y**
undo and redo every schema edit. All shortcuts: [Keyboard shortcuts](../../reference/keyboard-shortcuts.md).
