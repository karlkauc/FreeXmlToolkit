# Guides

Each guide covers one job: editing a document, designing a schema, validating, transforming,
publishing. Pick the task you have in front of you.

<div class="grid cards" markdown>

-   **[Edit XML](edit-xml/index.md)**

    Text, Tree and Grid views, auto-completion, templates, favorites, bookmarks and very large files.

-   **[JSON & YAML](json-yaml.md)**

    The same three views for JSON, JSONC, JSON5 and YAML, with JSON Schema validation.

-   **[Design schemas](design-schemas/index.md)**

    The graphical XSD editor, type library, schema analysis, documentation and sample XML.

-   **[Validate](validate/index.md)**

    XSD, DTD, RELAX NG and Schematron, single files or whole folders, with Quick Fixes.

-   **[Transform & query](transform-query/index.md)**

    XSLT, XQuery, XPath and XProc: run, preview, debug, profile and test with XSpec.

-   **[PDF with XSL-FO](publish-pdf.md)**

    Render XSL-FO to PDF with Apache FOP or an external processor.

-   **[Compare and merge](compare-merge.md)**

    Compare two files as text or as XML, compare folders, merge three versions.

-   **[Convert formats](convert.md)**

    XML, JSON and YAML into one another; XML to Excel or CSV and back.

-   **[Sign & encrypt](sign-encrypt/index.md)**

    XML signatures and XML Encryption for documents and single elements.

-   **[Projects & scenarios](projects.md)**

    Bind schemas to files by pattern and keep named transformation scenarios in one project file.

-   **[AI assistant](ai-assistant.md)**

    Explain and fix validation problems, write queries and stylesheets; off by default.

</div>
