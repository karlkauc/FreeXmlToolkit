    Comparison with Other XML Editors¶

    This page compares the features of FreeXmlToolkit with three other XML editors, so you can check whether it covers what you need. It lists facts only and shows where the other editors offer more.

    FreeXmlToolkit's AI assistant works with a model you choose — on your computer (Ollama, LM Studio) or a service you have an account with — and needs no subscription. Data levels and a request preview control what leaves your computer, and nothing is applied without you. fxt-cli mcp gives an AI agent of your choice the validation, XSLT/XQuery, XSpec and schema tools over the Model Context Protocol, restricted to the folders you name. See MCP Server.

    Where the Others Offer More¶

    FreeXmlToolkit focuses on XML, XSD, XSLT and XQuery development. It edits DTD and RELAX NG schemas as text only (with validation and auto-completion for documents that use them), and it does not edit files larger than its memory limit (the Large File Viewer is read-only). The other products cover areas that FreeXmlToolkit does not:

    • Oxygen XML Editor:
      • authoring and publishing for DITA, DocBook and TEI;
      • a visual (CSS-based) author mode with change tracking;
      • connections to XML databases, content management systems and WebDAV;
      • an Eclipse plugin and a web-based editor (separate product);
      • an AI assistant (paid add-on).

    • XMLSpy:

      • database connections;
      • code generation for Java, C# and C++;
      • a WSDL editor and a SOAP client;
      • an XBRL taxonomy editor;
      • Authentic view;
      • charts from XML data;
      • Visual Studio and Eclipse integration;
      • an AI chat (separate subscription).

    • XMLBlueprint:

      • refactoring (rename or split elements, rename namespace prefixes);
      • editing files on FTPS, SFTP and WebDAV servers;
      • CSV and Excel to XML conversion;
      • a user interface in 21 languages.
