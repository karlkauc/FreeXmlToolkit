PDF mit XSL-FO

Aus XML und einem Stylesheet wird ein PDF, angezeigt in der Anwendung.

  • Apache FOP eingebaut, mit PDF/A-1b-Ausgabe
  • Das Zwischenergebnis (FO) und jede Meldung des Prozessors griffbereit
  • Antenna House, RenderX XEP oder ein anderer Prozessor statt FOP
  • Von der Kommandozeile mit fxt-cli fop

Signaturen

Signieren und prüfen

XML-Signaturen mit den Algorithmen, die Sie wählen.

  • RSA, RSA-PSS und ECDSA
  • RSA- oder EC-Zertifikate für Tests erzeugen
  • Keystores, PEM- und DER-Dateien
Zur Dokumentation (englisch)
Verschlüsselung

Elemente oder ganze Dokumente verschlüsseln

XML Encryption 1.1 für ein Element, seinen Inhalt, das Dokument oder eine Binärdatei.

  • Beliebig viele Empfänger: Zertifikate, gemeinsame Schlüssel oder ein Passwort
  • Eine verschlüsselte Datei untersuchen, bevor Sie sie entschlüsseln
  • „Encrypt Element“ und „Decrypt“ im Kontextmenü des Editors
Zur Dokumentation (englisch)
