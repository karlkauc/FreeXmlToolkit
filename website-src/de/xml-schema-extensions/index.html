Namensraum

XML-Schema-Erweiterungen

Diese Adresse ist der Name eines XML-Namensraums. FreeXmlToolkit schreibt einige eigene Elemente in xs:appinfo eines Schemas, und diese Namensräume kennzeichnen sie. Von hier wird nichts geladen: Der Name eines Namensraums muss nur eindeutig sein.

http://freexmltoolkit.org/xml-schema-extensions

fxt:exampleValues enthält Beispielwerte eines Elements oder Attributs. Das Toolkit zeigt sie in der erzeugten Dokumentation („Sample Data“), bietet sie in der Autovervollständigung des Editors an und verwendet sie beim Erzeugen von Beispiel-XML.

<xs:appinfo>
  <fxt:exampleValues xmlns:fxt="http://freexmltoolkit.org/xml-schema-extensions">
    <fxt:example value="TRX-0815"/>
  </fxt:exampleValues>
</xs:appinfo>

Die Altova-Form altova:exampleValues (Namensraum http://www.altova.com/xml-schema-extensions) wird ebenfalls gelesen.

http://freexmltoolkit.org/schema/flattening

fxt:sourceFile hält fest, aus welcher eingebundenen Datei eine Komponente stammt, wenn ein Schema aus mehreren Dateien zu einer zusammengeführt wird.

Andere Schema-Prozessoren

Validatoren ignorieren den Inhalt von xs:appinfo, diese Elemente ändern also nichts daran, wie ein Schema validiert.

Alle Angaben, die das Toolkit aus Schema-Anmerkungen liest: XSD documentation tags (englisch).
