What is new

Short notes on each release. The complete list of changes is in the documentation.

22 November 2026

3.5.0: A new look, Saxon HE 13.1 and bookmarks

A new logo and one colour scheme throughout the application, its installers and the schema documentation. Saxon HE 13.1 can be added as an extra XSLT processor, the Query Console declares the document's namespaces and shows hits while you type, stylesheet errors point to the failing expression, and bookmarks mark lines across files. The documentation is newly ordered by task.

Release notes and downloads

18 November 2026

3.4.0: Query errors you can act on

Failed XPath and XQuery runs show the error code, position, a hint and "Did you mean" corrections. The Problems panel groups findings and exports them to Excel, the Graphic view inserts new elements where the schema wants them, and FundsXML gains 37 more data-quality checks.

Release notes and downloads

16 November 2026

3.3.0: Regulatory reporting, YAML and online identifier lookup

Extensions for Austrian pension fund and management company reports to the FMA and for ESMA reporting (EMIR, SFTR, MiFIR). LEIs and ISINs can be checked at GLEIF, ESMA FIRDS and OpenFIGI. YAML gets an editor with JSON Schema, tree and grid; large files can be edited in windows; stylesheets can run on external XSLT processors.

Release notes and downloads

13 November 2026

3.2.0: Older language versions

An expert mode runs and checks XPath, XQuery, XSLT and XSD in older language versions. XPath results show as a table, and syntax colour schemes like those of oXygen and XMLSpy are available.

Release notes and downloads

11 November 2026

3.1.0: AI assistant and MCP server

An AI assistant, off by default, whose answers are checked before you see them, and fxt-cli mcp for AI agents. The appearance follows the system theme, with accent colour, editor font, text size, density and high contrast.

Release notes and downloads

9 November 2026

3.0.0: Command line, policies and plugins

A German user interface, the fxt-cli command line, machine-wide administrator policies, plugins and the first industry extensions, projects with transformation scenarios, DTD and RELAX NG, compare and merge, conversion, the Large File Viewer and the XSLT profiler.
