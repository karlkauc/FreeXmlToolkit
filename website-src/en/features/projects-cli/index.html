Projects

One project file

A .fxtproj file sits next to your data and can be shared with the team.

  • Bind a schema, a Schematron and a scenario to files by pattern
  • XML catalogs of the project
  • Validate the whole project in one run

Scenarios

Regression checks for transformations

A scenario names a stylesheet, its input and the result that is expected.

  • Check compares the result with the expected file
  • Differences open in the compare view; Accept takes the new result
  • As fxt-cli scenario --check with a JUnit report
