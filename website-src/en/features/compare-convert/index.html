Compare, merge, convert

See what really changed between two documents, and move data between formats.

CompareFoldersMergeConvert
Compare

Differences in the structure, not in the characters

The XML mode compares elements and attributes, so formatting and attribute order do not count.

  • Ignore parts of the document by XPath
  • A tolerance for numbers
  • A text mode for everything that is not XML
Read the documentation
Folders

Two folders side by side

Which files were added, removed or changed, and the differences of each.

  • Open the comparison of a file from the list
Read the documentation
Merge

Three-way merge

Bring two changed versions of a file together with their common ancestor.

  • Conflicts are marked the way Git marks them
  • Also as fxt-cli merge
Read the documentation
Convert

XML to Excel and back

Records of an XML document become rows of an Excel or CSV table, and the table becomes XML again.

  • One row per record, with a preview before the export
  • XML, JSON and YAML in any direction
  • Also as fxt-cli convert
Read the documentation
