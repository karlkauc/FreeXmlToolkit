Privacy

This website sets no cookies, uses no tracking scripts or analytics services and loads no fonts or scripts from other servers. Visits are only counted as anonymous day totals from the server log files.

Server log files

When you open a page, our web server records technical data that your browser sends: IP address, date and time, the page requested, the referring page, the browser and operating system. The server is rented from Hetzner Online GmbH (Germany) and located in the EU. This is needed to deliver the website and keep it secure (Art. 6 (1) (f) GDPR). The data is not combined with other data and the log files are deleted after 14 days.

Once a day we count from these log files how many people visited the website: visitors per day, the pages opened, the referring website, country, device type, browser and operating system. Only these day totals are kept. IP addresses and browser details are not stored for this; they are turned into a random value that is discarded when the count is done, so a visit cannot be traced back to you or linked to another day. Requests from search engines and other automated programs are counted separately. No cookies or tracking scripts are used for this (Art. 6 (1) (f) GDPR: our interest in knowing which pages are read).

Latest version from GitHub

The download buttons ask GitHub's public interface (api.github.com) for the latest version, directly from your browser, so that they point to the current files. GitHub then receives your IP address and browser details. The downloads themselves are delivered by GitHub. GitHub's privacy statement applies: GitHub General Privacy Statement. The answer is kept for an hour in your browser's session storage, which is deleted when you close the tab.

Links to other websites

Links to GitHub, the documentation (hosted on GitHub Pages) and other websites take you to their operators, whose privacy statements apply there.

The application

What the FreeXmlToolkit application itself sends - anonymous usage statistics you can switch off - is described in the documentation: Privacy and telemetry.
