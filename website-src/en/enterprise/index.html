Enterprise

Ready for managed desktops

For administrators and security reviewers: how FreeXmlToolkit is rolled out, which settings you can lock, what it sends over the network and how it is protected.

Silent installation

MSI and exe for Windows, pkg for macOS, deb and rpm for Linux, all installable without user interaction. Also in Scoop and Homebrew.

Installation and policies

Machine-wide policies

A policy.properties file locks settings for every user: updates, telemetry, AI, network access, external processors and plugins. defaults.properties sets defaults users may change.

Policies

Works offline

Validation, transformation and documentation run without internet. Schemas come from the Schema Library, OASIS catalogs or a shared folder; updates can be switched off.

Operation without internet

Secure by default

Protection against XXE, SSRF and unsafe stylesheets; external entities, remote schemas and extension functions are controlled by settings an administrator can lock.

Security features

Threat model and SBOM

A documented threat model says what the application defends against and what it does not. Every release ships a CycloneDX SBOM and SHA-256 checksums.

Threat model

Signed packages

macOS packages are signed with a Developer ID and notarized by Apple. How releases are built and signed is documented.

Code signing
Telemetry, openly

What the application sends, and how to stop it

Anonymous usage statistics and error reports are on by default and can be switched off by the user or for everyone with a policy. They contain feature names, counts, timings, the operating-system family and a random installation id - never file names, paths, document content, prompts or AI answers.

Privacy and telemetry in detail
# /etc/freexmltoolkit/policy.properties
fxt.telemetry.disabled=true
update.allowed=false
ai.allowed=false
security.dtd.allowed=false
Accessibility

Usable with keyboard and screen reader

Every control has an accessible name, text meets WCAG AA contrast, a high-contrast mode raises it to 7:1, and the interface scales from small to extra large with a compact or roomy density.

Accessibility
AI under control

Off unless you allow it

The AI assistant is off by default and needs a provider you configure. Administrators remove it completely with ai.allowed=false; the MCP server for agents has its own switch.
